# Vinhomes Grand Park Landing Page

Landing Page frontend tĩnh cho chủ đề bất động sản Vinhomes Grand Park tại thành phố Thủ Đức.

## Công nghệ

- HTML5
- CSS3
- Bootstrap 5 CDN
- Vanilla JavaScript

Không có backend.

## Cấu trúc

```text
.
├── GEMINI.md
├── SPEC.md
├── CHECKLIST.md
├── README.md
├── index.html
├── styles.css
├── script.js
└── assets/
```

## Dùng với Antigravity

`GEMINI.md` là file context/instruction chính của project. Antigravity/Gemini tooling hỗ trợ `GEMINI.md` làm context cho project; các tài liệu/spec có thể được tách riêng để agent tham chiếu.

Trong phiên làm việc, có thể yêu cầu agent:

> Đọc `GEMINI.md`, `SPEC.md` và `CHECKLIST.md`, sau đó triển khai Landing Page. Không hỏi lại nếu các yêu cầu đã đủ rõ. Tự kiểm tra theo checklist trước khi hoàn tất.

## Chạy website

Không cần build.

Mở trực tiếp:

```text
index.html
```

Hoặc chạy một static server nếu cần kiểm tra hành vi của browser với tài nguyên local.
